## Usage

```tsx
import { EmojiReaction } from "@/components/ui/emoji-reaction";

export function MyComponent() {
  return (
    <EmojiReaction
      defaultReactions={[
        { emoji: "👍", count: 12, reacted: true },
        { emoji: "🎉", count: 5 },
      ]}
    />
  );
}
```

### Controlled

```tsx
const [reactions, setReactions] = useState<Reaction[]>([]);

<EmojiReaction reactions={reactions} onReactionsChange={setReactions} />;
```

### Custom emojis

```tsx
<EmojiReaction emojis={["🚀", "💯", "🙏", "🤔"]} />
```

## Props

| Prop                | Type                              | Default                   |
| ------------------- | --------------------------------- | ------------------------- |
| `reactions`         | `Reaction[]`                      | —                         |
| `defaultReactions`  | `Reaction[]`                      | `[]`                      |
| `onReactionsChange` | `(reactions: Reaction[]) => void` | —                         |
| `emojis`            | `string[]`                        | `👍 ❤️ 😂 😮 😢 🎉 🔥 👀` |
| `hidePicker`        | `boolean`                         | `false`                   |
| `disabled`          | `boolean`                         | `false`                   |

`Reaction` is `{ emoji: string; count: number; reacted?: boolean }`. A reaction is removed once its count reaches `0`.
